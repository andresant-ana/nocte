# NOCTE-P1B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Exact model EV and a reproducible counterfactual composition benchmark for Issue #5.

**Architecture:** Keep the P1A engine and legacy CLI intact. Add an independent DP solver and exhaustive weighted scenario enumerator to the offline sim package; run all composition agents through the engine with identical optimal action policy and named card streams.

**Tech Stack:** Existing strict TypeScript, pnpm, Vitest and fast-check; Node crypto for domain-separated benchmark streams.

**Spec:** GitHub Issue #5 and docs/LAB-P1B.md.

## Global Constraints

- DF-SYM-0.1, infinite-rank-with-replacement, S17; existing EXPERIMENTAL 3:2/1:1 profiles.
- No UI, networking, finite shoe, asymmetric implementation, credits or deployment.
- No hidden dealer information or seed in solver decisions; composition is ex-ante.
- No automatic merge or promotion of rules to RATIFIED.

## Review Focus

- Peek conditions must exclude only the natural-making hole rank and normalize the remainder.
- Soft Ace transitions must not treat post-hit 21 as a natural.
- Three indexed pairings and distinct rank partitions are different random baselines.
- Different action counts must not shift another hand's or dealer's stream.
- One-scenario output must report variance/interval as unavailable; timing metadata is nondeterministic.
