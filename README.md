# NOCTE

**Status:** discovery / rules laboratory — no production game deployed.
**Authoritative documentation:** [docs/INDEX.md](docs/INDEX.md) (to be added in the documentation baseline).
**Repository:** independent project. The earlier MESA/21 direction was discontinued and is not the basis of NOCTE.

NOCTE is a browser-native, Art Déco / noir, blackjack-inspired strategy card game for solo and social play. Its lead design hypothesis is **Duas Faces**: compose four cards into two hands and compete on comparable scenarios.

## Decision discipline

A requirement approved by the founder is not the same as a laboratory hypothesis. Every entry in the decision ledger will specify status, rationale, evidence, and change control. Until the baseline lands, **do not interpret this README as an authorization to implement unvalidated mechanics**.

No real-money deposits, withdrawals, cash-equivalent rewards, purchased gameplay advantage or transfer of fictitious credits. Initial target: small group (~20 friends), zero initial infrastructure spending. Premium presentation follows gameplay validation.
